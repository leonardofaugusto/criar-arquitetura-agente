# criar-arquitetura-agente

Skill do Claude Code que cria ou revisa a arquitetura de um sistema com agentes, começando pelo Cérebro (o que o agente precisa saber e onde isso mora) e conectando produto, fluxo, dados, ferramentas, decisões e operação em Markdown com diagramas Mermaid.

## Instalar

```bash
git clone https://github.com/leonardofaugusto/criar-arquitetura-agente ~/.claude/skills/criar-arquitetura-agente
```

Depois, no Claude Code: `/criar-arquitetura-agente`.
